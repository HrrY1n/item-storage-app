# 物品分类

当前默认分类为 **7 个一级、49 个二级**，涵盖现有 220 个图标。一级保持宽泛；二级用于具体归档。用户可在“管理”中继续调整，默认数量不是用户自定义数量的硬限制。

| 一级分类 | 二级分类 |
|---|---|
| 数码与电子 | 电脑设备、手机与平板、音频设备、存储设备、配件与线材、键鼠与输入设备、摄影摄像、游戏设备、网络与智能设备、智能穿戴 |
| 学习与办公 | 书籍与阅读、笔记本与纸品、文具、文件资料、办公设备、桌面收纳 |
| 衣物与穿搭 | 上衣、裤装与裙装、外套、鞋履、包袋、配饰、贴身衣物、运动与家居服 |
| 生活与护理 | 随身日用、旅行用品、洗漱与美发、护肤与美妆、清洁与衣物洗护、健康与用药、五金与修缮、日常收纳 |
| 家居与厨房 | 家具与陈设、床品与布艺、照明用品、家用电器、家庭影音、厨房电器、锅具与厨具、餐具与杯壶、厨房收纳 |
| 兴趣与收藏 | 运动健身、球类运动、户外与骑行、音乐与乐器、绘画与手作、玩具与模型、卡牌与拼图、纪念与收藏 |
| 其他 | 直接归入“其他” |

Pocket 和 Action 归入“摄影摄像”，拓展坞归入“配件与线材”，平板磁吸键盘归入“键鼠与输入设备”。每个图标的完整类型对应保存在 [分类定义](../src/data/categories.ts)，测试会检查遗漏和重复。

## 现有数据如何更新

- 默认“生活用品”改称“生活与护理”，“收藏与纪念”改称“兴趣与收藏”；“书籍”扩为“书籍与阅读”，“裤装”扩为“裤装与裙装”。ID 保留，物品仍属于原分类。已改成自定义名称的分类保留原名。
- 增加“家居与厨房”和缺失的新二级分类，为旧二级分类补上代表图标。已有同名分类复用，已删除分类不复活；缺失的旧默认二级分类也不按原名重建。
- 更新只发生一次。之后在管理页改名、移动或删除不会在下次启动时被撤销；完全自定义的分类树不自动插入默认树。
- 分类变更与待同步记录在同一事务提交，原待同步记录保留；云端失败不影响本地更新。云端恢复仍以云端分类为准，旧设备启动产生的新增分类按正常同步传播。
- 备份包含默认分类内容版本；旧 ZIP 在恢复事务里补齐，新 ZIP 保留已完成的自定义整理。数据结构和同步协议不变。

## 分类页

顶部显示当前实际一级、子分类和物品总数；每个大类默认展开二级网格，可单独折叠。子分类显示名称、封面和实际物品件数，点击进入对应物品列表；“全部”查看该大类及全部后代。件数统计未删除物品，与分类详情使用同一口径。

旧物品如果直接放在一级分类中，会提示“另有 N 件物品直接归入此大类”，不自动迁移到某个新子类。分类页展示的是业务分类；图标选择器仍使用九个素材分组。
