# AI 辅助录入

支持单张物品照片或订单截图，识别候选名称、现有分类、备注及订单中的购买信息。用户可直接修改结果、选择现有分类，再勾选字段填入当前表单；点击原有保存按钮才写入 IndexedDB 并进入既有同步流程。心愿物品不填购买字段。原图只用于本次识别，不进入本应用数据库、备份或日志。

## 接入与免费边界

固定使用 Cloudflare 托管视觉模型 `@cf/qwen/qwen3.8-27b`，绑定名 `AI`。不提供用户指定模型、外部 URL、工具调用、自动重试或模型切换。

Cloudflare 官方当前列出该模型的 Vision 能力，未列入其 Paid-only 模型清单。[模型说明](https://developers.cloudflare.com/workers-ai/models/qwen3.8-27b/)、[计费与免费额度](https://developers.cloudflare.com/workers-ai/platform/pricing/)

**免费依赖部署账号保持 Workers Free。** 其 AI 每日额度用尽时调用失败；Workers Paid 超过免费额度可能计费。`AI_FREE_PLAN_CONFIRMED` 是运营确认开关，不是平台套餐检测器，不能在 Paid 账号上用它宣称永不收费。未确认时必须为 `false`，此时服务返回 503，模型不会执行；本账号已确认后设为 `true`。若账号改为 Paid，应先关闭该开关并重新核对费用策略。

启用步骤：

1. 用自己的现有 Cloudflare 账号登录 Wrangler，确认目标账号和 Workers Free 套餐；不要创建临时账号或升级套餐。
2. 确认后把 `wrangler.jsonc` 中 `AI_FREE_PLAN_CONFIRMED` 改为字符串 `true`。`ai.binding` 已配置为 `AI`，不需要额外模型 API Key。
3. 构建、验证并部署现有 `item-storage-app` Worker。D1 表和本地数据模型不需要迁移。
4. 本设备需已完成设置页里的云端配对。AI 复用配对凭据；暂停同步不会取消 AI 权限。未配对、未绑定、未确认免费计划时，手动录入继续可用。

## 数据与接口

`POST /api/ai/recognize` 复用现有 Bearer 认证；仅接受内联 JPEG，拒绝远程图片地址。浏览器将最长边缩到 1600 像素以内，重新编码为至多 400 KiB 的 JPEG，原始文件上限 15 MiB。可通过上下边界在本机裁剪，先从原始图片取选区，再缩图；高宽比超过 3.5 的长截图需先选取局部，避免压成无法阅读的细条。裁剪确认不发起推理，仍需明确点击「开始识别」。请求流上限 560 KiB，不依赖 Content-Length 才做限制。模式为 `photo` 或 `order`；附带至多 100 个当前可用、名称唯一的末级分类名称，帮助模型匹配已有分类。

请求内容不写入日志。模型仅生成数据，输出经过长度、日期、金额、平台等逐字段校验；无效字段置空并提示，保留其余有效结果，不纠正或猜测金额与日期。无可用字段或无法解析的 JSON 仍明确失败。提示最多五条、每条最多 200 字符。照片模式先忽略购买价格/日期/平台，再校验有效外观字段，避免无关的购买信息破坏整份结果。分类只匹配唯一现有名称；未匹配时可在结果中选择现有分类，不接受模型给出的数据库 ID，也不自动建分类。多商品订单只处理一件，并要求用户核对金额归属。

已有字段默认不勾选；主动勾选后才覆盖对应草稿值。AI 不直接创建物品、标签、同步记录或保修设置。用户选择填入购买日期时，现有保修/日均规则正常联动。

开始、取消、重试和填入操作固定在面板底部，适配安全区域；识别结果、错误和裁剪区出现后自动定位。结果可编辑，手动修改的字段自动勾选；填入前再次校验。未选字段时明确提示勾选或关闭后手动填写。切换图片立即使旧图与旧结果失效，换图准备失败也不会提交上一张图片；取消文件选择不影响当前图片。

超时、离线、额度不足或无效返回会保留当前表单。取消识别会中止浏览器等待并忽略迟到结果；已经发送的推理可能仍在服务商执行及占用免费额度。后端设 45 秒等待上限，前端 60 秒；单次限制生成 1024 tokens，并有 isolate 内 5 秒间隔保护。多用户场景需要升级为持久化限流。
