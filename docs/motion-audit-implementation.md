## 审计判断经运行验证后的调整

审计指出卡片内部展开与相邻行衔接不足。实际检测中，下一行从 1199.75px 跳到 1285.75px，仅出现两个不同位置。计算样式进一步确认：`html.theme-shift main div` 将卡片 disclosure 的 grid 过渡覆盖成只有颜色过渡。

因此对展开控件保留自身过渡，修正主题选择器后，逐帧样本出现连续中间位置。没有再给同一段连续高度变化叠第二套逐帧 FLIP。新增的位移增强仅用于离散的结果重排和视图切换。`h-full` 尺寸假设曾做最小试验，未改善，已撤回。

日期和图标库退出需等动画结束；相关旧测试中“按 Escape 后立即查无节点”的断言改为等待实际退出完成，仍保留超时失败，不通过强制结束动画掩盖问题。

## 当前交互约定

- 搜索取消保留关键字，仅退出聚焦；清空单独操作，不主动收起键盘。这是本轮采用的保守默认，可根据用户真机反馈调整。
- 进入编辑使用同一层面板。取消未保存修改仍按原确认流程处理；返回详情恢复原滚动，最终关闭才恢复来源列表焦点/位置。
- 日期年月日只改日期草稿，确认才提交；取消、Escape 或下拉均不提交草稿。
- 内层选择器与确认框仍只关闭自己，已滚动正文的手势保持原生，不在途中抢成关闭手势。
- AI 的候选确认、取消迟到响应、免费计划确认开关和保存链路均沿用原实现。
