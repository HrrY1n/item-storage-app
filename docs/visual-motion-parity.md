## 动效调校与连续性

- 完整面板入场候选值 480ms，选择器 340ms，退出 300ms；未关闭的拖动回弹单独使用 260ms。保留原来的方向/距离/速度判断，这些值没有被声称为原生弹簧参数。
- 方向判定期间入场或回弹还可能继续移动；正式接管拖动时重读当前视觉 Y，避免使用按下时的旧位置。
- 面板高度变化被关闭打断时，冻结当前可见高度并取消高度动画，使退出位移的终点稳定；重新打开后释放临时高度。暂停中的高度动画也覆盖此路径。
- 保留快速反向、最上层手势归属、已滚动正文不抢手势、未保存确认、取消后保留输入、减少动态效果等行为。
- 原片没有足够证据支持新增明显背景缩放，因此只保留遮罩与拖动位移的协调。此前名为 category-height 的序列前段是来源选择器退出，后段是分类选择器进入，不能据此认定同一个面板自动切换停靠高度。

逐帧复现了新增面板的突然露出：原生 dialog 的自动聚焦把外层滚动了约 513px，使本应在屏幕外的面板提前进入视口；异步数据到达后，占位内容替换为表单，又使面板高度从 720px 变成 832px。现在只裁切弹层外框的溢出，滚动继续由内部面板负责；初次入场等待表单就绪，详情与编辑切换仍沿用同一个面板。载入期间内容透明且 inert，减少动态效果时面板直接显示并正确接收焦点。

## PWA 更新过渡（2026-10-23）

发现新版本后先显示「发现新版本／正在应用更新」，保留约 650ms，再应用新版；真正刷新前复查编辑状态、页面可见性和重复刷新保护。过渡期间进入编辑或切到后台会取消这次刷新，恢复安全状态后重新开始过渡。

旧文档和新 HTML 共用同一套浅色／深色更新遮层。新 HTML 在加载应用脚本之前显示恢复画面，覆盖 Boot 读取本地数据时的空内容阶段。应用就绪后恢复原 URL 的滚动位置和主内容焦点，淡出遮层并提示一次「已更新到最新版本」。减少动态效果时禁用旋转与淡入淡出。启动失败时撤掉遮层，显示原有错误信息，不报告更新完成。

恢复信息仅保存在当前标签的 `sessionStorage`：时间、同一路径和滚动坐标，有效期 120 秒，成功后即消费。它不进入 IndexedDB、备份或云同步。存储不可用时更新仍继续，但不能保证跨页面保留位置和完成提示。已经运行的旧客户端尚无这套逻辑，首次升级仍可能按旧流程刷新，完整过渡从新版装好后的后续更新生效。

验证：类型检查、840 项单元测试和正式构建通过；真实 Service Worker 的两套生产构建之间 53 项浏览器检查通过，包含相同 URL 图标替换、原有数据与 outbox 保留、编辑保护、无更新／失败／离线，以及 390px 浅色、1280px 深色减少动效和 4 倍 CPU 降速下的提示停留、空 root 首帧覆盖、滚动／焦点恢复与完成提示单次消费。截图与逐帧记录保存在 `.tmp/icon-v2-pwa-swap-*`，汇总沿用原有 PWA 验证报告。

## 液态玻璃导航（2026-10-23）

这是一套网页材质近似，未调用 Apple 原生 Liquid Glass，也未使用 Safari 尚有兼容问题的 SVG 背景位移滤镜。桌面继续使用原侧栏；减少透明度、增加对比度或强制颜色时使用实色，减少动效时禁用按压形变。高光不拦截点击，保留原有链接、44px 触控区、键盘焦点及新增面板的背景/焦点恢复。
