## 动效调校与连续性

- 完整面板入场候选值 480ms，选择器 340ms，退出 300ms；未关闭的拖动回弹单独使用 260ms。保留原来的方向/距离/速度判断，这些值没有被声称为原生弹簧参数。
- 方向判定期间入场或回弹还可能继续移动；正式接管拖动时重读当前视觉 Y，避免使用按下时的旧位置。
- 面板高度变化被关闭打断时，冻结当前可见高度并取消高度动画，使退出位移的终点稳定；重新打开后释放临时高度。暂停中的高度动画也覆盖此路径。
- 保留快速反向、最上层手势归属、已滚动正文不抢手势、未保存确认、取消后保留输入、减少动态效果等行为。
- 原片没有足够证据支持新增明显背景缩放，因此只保留遮罩与拖动位移的协调。此前名为 category-height 的序列前段是来源选择器退出，后段是分类选择器进入，不能据此认定同一个面板自动切换停靠高度。

## 验证

使用项目专用 Edge launcher/Profile，不接触日常浏览器或生产物品；测试结果和截图留在 `.tmp`，原录屏不随仓库发布。模拟 AI 用例不调用真实模型。

执行入口：`npm run typecheck`、`npm test`、`npm run build`；`scripts/verify.mjs`、`verify-interactions.mjs`、`verify-design.mjs`、`verify-recognition.mjs`、`verify-warranty.mjs`、`verify-reduced-motion.mjs`。本轮新增覆盖紧凑工具栏、初始展开、分类/来源内层选择、回弹重新接管，以及高度动画中退出/重新打开。

最终结果：类型检查、53 个测试文件中的 802 项单元测试、生产构建通过。隔离浏览器共 205 项检查通过：交互 53、布局/主题/键盘 99、模拟 AI 11、物品流程 9、日期/保修 29、减少动态效果 4。已复核手机列表、详情、编辑、深色表单及桌面详情截图。构建仍保留原有主包超过 500KiB 的提示，本轮没有增加依赖。

历史购买/费用/备份脚本已更新新选择器入口并检查语法，没有为此次外观验收执行旧的清库工作流。

## 真机边界

仍需 iPhone Safari 与主屏 PWA 对照：真实键盘/中文输入、安全区、滚动惯性、手指快速反向和系统减少动态效果。桌面移动视口不能证明 iPhone 帧率，也不能证明所有原生系统控件逐像素一致。未观察的菜单与业务流程仍以现有独立实现为准。
