# 产品目标

## 一句话

一个 **local-first、私人、长期自用、低维护成本、移动端优先**的数字物品库。

## 记录范围

优先记录较昂贵的设备，以及有意思、有纪念意义或值得长期追踪的小物件。不要求把廉价附件和日常消耗品逐项建档，图标按实际使用需求取舍。

## 核心功能

物品 · 分类树 · 标签 · 搜索 · 统一图标 · 购买信息 · 总投入 · 日均使用成本 · 私人跨设备同步（可选）· Backup · PWA

## 保留的交互与视觉偏好

- 保修状态保留分段点阵、剩余时间与百分比，不因统一极简样式而改成连续细线。无法计算进度时只显示可确认的到期信息，不虚构比例。
- 物品网格卡片的明细支持独立展开、收起；保修条在两种模式下均可见。展开按钮与进入详情的链接分开，收起状态保留物品名称、分类、标签和图像。

## 长期非目标

以下方向**不属于本产品的定位**，不是"暂时不做"，而是长期不追求：

- 位置树（东西放在哪个房间/格子）
- 家庭多人协作
- 企业库存管理
- 进销存 / 财务流水
- 账号系统
  - ❌ 不做**公开、多用户账号体系**：不注册、无邮箱登录、无密码找回、无 OAuth、无用户中心、无多租户 SaaS
  - ✅ 允许**可选的单用户私人跨设备同步**：由用户自持的随机 secret 授权，设备数不限，不承载任何第三方内容（Phase 3A 设计 / Phase 3B 实现）
- 社交
- 复杂 Dashboard

## 如何区分 Product Goal 与 Phase Scope

- **Product Goal**（本文）描述产品长期要成为什么，变更需重新讨论定位。
- **Phase Scope**（任务指令 / `docs/architecture.md`）描述当前阶段做到哪里，阶段结束后可扩展，不改变长期定位。

某功能"本阶段没做"，只说明它不在当前 Phase Scope 内，**不代表产品永久禁止**；只有写入本文「长期非目标」才是永久排除。例：AI 图标、照片转绘属于后续 Phase Scope，不是长期非目标。
